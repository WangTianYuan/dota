# 主角能力评分与版本适应：工作设计

ID: story:ability-rating-working-design
更新：2026-09-15
状态：作者已批准“综合评分＋少量分项＋水平标签”。下列具体标尺、初值和版本呈现为主任务提出的可回调设计，不是全部已经锁定的设定。所有评分均为X小说设计，不是现实选手统计。
依据：[系统基线](system-training-baseline.md)、[已锁决策D22](locked-decisions.md)、[当前前期骨架](batch-012-opening-outline.md)。

## 1. 一张小面板先回答主角有多强

主位置：二号位。综合评分反映已经形成、可迁移的个人竞技能力；分项先只保留对线能力、团战处理、地图判断。操作与信息使用在这三个场景中体现，暂不另列反应、天赋、潜力、沟通、情绪等一大排分数。

| 候选分数段 | 读者看到的水平标签 |
|---|---|
| 70—79 | 高分天梯 |
| 80—84 | 职业水准 |
| 85—89 | 一线职业级 |
| 90—94 | 世界顶尖 |
| 95—100 | 时代标杆 |

这些是稳定的叙事标尺，不是每季重排的百分位，也不逐一对应现实MMR或某位真人。低于70的细分在情节需要时再定。100是此标尺的上沿，不表示全知、没有失误或必胜；到顶后的竞技变化仍可来自打法、对手、团队和版本，不靠不断追加新上限续写。

综合不是三项的固定算术平均，也不按短板自动封顶。它给出整体判断，分项解释强在哪里。作者后台记录前后变化的理由即可，不写加权公式给读者。职业水准只说明个人能力，不自动提供职业席位、完整英雄池和五人默契。

## 2. 初始面板候选

> 主位置：二号位
>
> 综合评价：76｜高分天梯
>
> 对线能力：80｜职业水准
>
> 团战处理：75
>
> 地图判断：73

用途：让读者知道他原本就强，对线已经有职业级的一面；系统帮助这种天赋更快成长。76/80/75/73只是当前提案，第一章选材后可以整体调整，不以“怕成长太快”压低数值。没有预定某章、某周必须涨到多少；允许早期明显跃升和强项迅速达到顶尖。

有明显变化时简写“综合评价：76→80｜职业水准”，再展开最相关的一项即可。能力是练成的，显示不是额外奖励；不要求每次训练都涨分，也不安排固定扣分制造挫败。

## 3. 版本变化怎样呈现

主面板描述已形成的能力，按需增加一行“当前版本适应”，描述这些能力在新环境里的掌握和运用情况。先试用“磨合中／熟悉／形成优势”等白话状态，不再增加适应百分比、版本加成或第二套总分。

- 补丁发布不自动清零或扣除能力；同样的操作、对线经验、学习与判断能力仍有价值。长期生疏或能力实际变化可以调整评分，不承诺永远只涨。
- 小平衡改动未必需要适应过程；擅长的英雄可能直接受益。不是每次更新都从“磨合中”开始，也不是每次先失败再学习。
- 熟练英雄被削，说明原来的使用条件可能变了，不等于突然不会操作。遇到英雄重做，新的操作与判断需要另练，不把旧熟练当成全部新技能已掌握。
- “形成优势”只指主角已有训练、复盘和对局中验证出的用法，不表示系统已知道全球Meta、全部反制或未来版本答案。
- 状态由主角实战外主动评估呈现；尚未验证的想法留在研究中，系统不提前宣布哪个英雄必成版本答案，也不把不确定性变成固定劝退弹窗。
- 一套打法被针对，未必是个人能力下降。故事可以写他改用已经准备的另一套，也可以写他在普通阵容里照样发挥。

例示（非初始值、非实际补丁结论）：综合评价88保持，当前版本适应从“熟悉”变为“形成优势”；之后比赛展示研究如何帮助他和队友打赢。若新的学习也提高了可迁移能力，则相应分项可以同步上涨，但不是版本发布自动加点。

## 4. 版本怎样形成情节

可按当前故事选择不同情况：擅长英雄变强带来快速兑现；原打法受影响，主角主动换一个更有意思的解法；研究出用法后，先在天梯试成，再和队友打成五人可用的战术；别人复制或针对，他拿出准备的变化。不是每个补丁按同一条流程演一遍，也不预定每次只有主角先懂。

强项和成长通过面板建立期待，具体比赛仍须有自己的过程与结果。长线服务作者澄清的主旨：回到TI10后的时间节点，借人物经历和选择改变CN Dota的具体问题。“挽天倾”是读者与真实历史对照时可能获得的感受，不是系统任务或主角必须完成的全面救世指标。研究和个人能力可通过真实合作影响队伍，不通过系统给全队加属性；夺冠年份、具体蝴蝶效应仍另定。

具体英雄、物品、地图规则与当期选人资格在采用前研究；本文件没有给任何真实版本新增机制或判定英雄强度，也不把后来的Meta倒灌给主角。
