# P2 / P3 八节点压力测试

ID: story-research:p2-p3-eight-node-pressure-test
更新：2026-09-12
状态：阶段性比较，不锁最终位置/首队/TI11名次。

## 评估前提

本轮使用已确认的新边界：

- 第一支正式职业队不要求五名中国选手，但同等条件下优先中国选手；
- 不预设主角必须经历“学会自己不是唯一答案”的思想教育；
- 主角可以达到世界顶级强度，Ame/XinQ等真人也可以保持世界顶级强度；
- 争冠队成立的核心是五个位置都足够强，并在版本、英雄、资源、职责、沟通和化学反应上形成整体；
- P2 = Aster.Aries 2号位 → 长期2；P3 = iG 4号位 → TI11后长期3；
- Ame + XinQ仍是未来主队高权重组合，不是已经锁定的最终名单。

评估规则不是“谁需要零蝴蝶效应”。小说本来就允许蝴蝶效应。真正比较的是：

1. 改动是否来自主角已经证明的能力；
2. 是否连续替真实人物作不符合其利益的选择；
3. 是否必须反复解释“为什么不用现实中更自然的答案”；
4. 改动发生后，后续历史是否能够自然重新推演，而不是一边改人一边照抄现实赛果。

# 节点1：TI10后前三个月怎么成长

## P2：继续以中单为主

### 路径

TI10 G5模拟之后，主角仍主要用2号位冲分：

- 对线是高频、反馈清晰的个人训练入口；
- 系统训练把“凭感觉知道什么时候能杀/能游走”逐步拆成兵线、符点、装备窗口、视野、支援成本；
- 3/4号位仍作为摇摆和学习工具，不承担长期职业身份。

### 优点

这是现有设定的最短路径：`高分路人主2 → 更高分的中单 → 职业中单候选`。

不需要为了未来阵容提前改变主角训练身份。

### 风险

如果前三个月只写对线和Rank上分，会把系统缩成“更高效练操作”。必须同时用历史模拟、复盘和平台活动让主角开始理解：职业Dota中，中单优势只有经过资源转换才有价值。

### 压力结果

**通过，改写成本低。**

---

## P3：从主2逐步转向4号位求职

### 路径

TI10首次模拟本身是4号位，可以触发主角主动研究信息、烟、视野、先手、支援和低资源决策。但要在2022春天以4号位被iG试训，仅靠一次系统模拟不够：

- 11—12月仍可以中单冲分；
- 之后需要显著增加4号位Rank/组排/平台赛样本；
- Zhou/ZSMJ及职业圈真正记住的不能只是“这个中单很强”，而要看到他在4号位也能影响比赛。

### 风险

职业队招聘看的是具体位置。若主角主要以中单成名，却突然以4号位拿到iG机会，会显得作者为了iG空位改位置。

### 压力结果

**可行，但已经需要第一层额外铺垫。**

# 节点2：第一次被职业圈正式认可

## P2

最自然的认可方式不是俱乐部经理看一局录像，而是三层累积：

1. 高分局反复遇到Zhou/ZSMJ及职业选手；
2. OB/平台活动中与现役选手同局，主角的ID从“高分路人”变成熟脸；
3. 训练赛/临时缺人时被推荐给需要测试中单的队伍。

由于Aries本身是年轻阵容，且现实在2022春季确实更换中单，主角进入其候选池不要求他先成为明星。

**通过。**

## P3

iG在TI10刚拿第四，是名气和履历都很高的俱乐部。现实中Kaka离队后选择的是已有职业经验的Frisk/Fade，而不是高分新人；Frisk也明确说iG正在经历风格转型阵痛。

如果主角想在几个月后替掉Frisk，必须已经拥有比P2更高的职业圈认可度：不仅“有天赋”，还要让iG相信他的4号位信息/先手能力可以解决真实缺口。

**勉强通过，但门槛高于P2。**

# 节点3：为什么队伍愿意给他试训

## P2：Aries中单

### 历史锚点

- 2021-11 White丶Album从Aster主队下放/转入Aries；
- 2022 Tour2期间，Xwy/一已经在4月实际代表Aries比赛；
- 5月18日，White丶Album正式被一替代；
- Aries随后以Tour2 A级6-1第二升入S级。

这说明“春季寻找/试用另一个中单”不是小说创造的需求，而是现实发生过的选择。

### 小说替换

主角竞争的是**现实已经出现过的试用窗口**，不是让一个稳定发挥的固定中单突然被老板开掉。

### 额外优势

Aries公开材料显示RedPanda、生死、Ulu等已有自己的指挥、版本研究和队内语言。主角不需要一加入就成为教练。

**强通过。**

---

## P3：iG四号位

### 历史锚点

- Kaka离开后，iG用Frisk/Fade替代；
- Frisk自述自己更偏操作、信息量不像Kaka那么多；
- Emo说换Kaka是为了体系求变，并非简单认为Kaka不行；
- BoBoKa后来也观察到没有Kaka后iG的节奏/先手发生变化；
- 现实里iG直到5月才再引入fy。

### 小说难点

现实确实存在“4号位结构没有完全解决”的空间，但主角要插入的是：

> Kaka → Frisk → fy

这样一个已经有两个成熟职业四号位答案的位置。

如果主角3—4月进入，就需要改变“等fy”的现实路径；如果5月才进入，则首年节奏又变慢。

**可行，但强改程度明显高于P2。**

# 节点4：第一场真正暴露职业差距的失败

## P2

现实Aries Tour2最终6-1，本来就不是无敌队伍。

最自然的写法不是让主角首秀被单杀十次，而是：

- 路人里正确的个人判断进入职业赛后，被对方信息、TP、辅助资源和BP上下文改变；
- 主角中路可能不输，但团队没能把中路线权变成目标；
- 或主角为了扩大优势过度占用地图资源，导致边路的阵容强势点错过窗口。

失败可以直接挂在现实存在的Tour2失利上，不需要额外制造“教育局”。

**强通过。**

## P3

iG现实Tour2是5-2，其中就存在对DEC、Aries等强队的失败空间；4号位的信息失误和先手决策也天然适合表现“Rank看得到机会 ≠ 职业比赛能安全发动”。

**强通过。**

这个节点两条路线都成立，区别只是学习内容不同。

# 节点5：第一次正式职业对阵Ame

## P2

Aries现实升入Tour3 S级后，**2022-06-24正式对阵PSG.LGD，0:2落败**；7月17日2—5名加赛又再次被LGD击败。

这是非常干净的第一次正式对阵：

- 主角已经不再是刚入行的路人；
- Ame所在LGD依然是世界顶级队；
- 不需要让主角第一次见偶像就赢；
- 中路直接面对NothingToSay，而真正的比赛目标却是如何限制/应对Ame，天然让主角从“看一个选手”升级到“看一整支LGD”。

如果主角个人发挥亮眼但队伍0:2输掉，更有利于后续尊重双方强度。

**极强通过。**

## P3

现实iG Tour2 A级只排第三，Tour3仍在A级；要在夏季正式遇到LGD，小说必须先让主角把iG从5-2第三提升到前二，从而改写升降级。

这并非不合理——iG与Aries现实只差一个胜场，且直接交手打满三局。但一旦iG升S，Tour3赛程、Aries去向等都会进入蝴蝶世界线，不能再精确照抄现实6月24日。

**可通过，但第一次对Ame之前已经必须先完成一次关键赛果改写。**

# 节点6：TI11资格路径与首年成绩上限

## 现实基线

2022中国TI地区预选：

1. RNG直接晋级TI11；
2. XG进入LCQ；
3. VG进入LCQ；
4. iG；
5-6. Aries / CDEC。

地区预选只给冠军直接TI名额，第二、第三去LCQ。

## P2：Aries

现实Aries已经打到5-6，最后1:2负于iG。

如果主角要首年进TI，最小的合理路径不是“直接把RNG、XG全部横扫”，而是：

1. 把对iG的1:2翻过来；
2. 再击败VG，拿到中国区第三、进入LCQ；
3. LCQ再打入前二，进入TI11。

### 成本

这需要主角所在队从“中国S级中游”真正跃迁为“国际TI级队伍”，不是只改一场。

但这种跃迁如果发生在一整个夏季/TI预选期，和系统训练、团队磨合一起推进，仍然可以作为第一年主高潮。

### TI正赛上限

建议仍不直接夺冠。`TI首年5-8名`已经足以把主角打成世界级新星，同时保留以后和Ame组队追盾的空间。

**可行，但从地区预选到TI深轮次需要一段真正的大成长。**

---

## P3：iG

现实iG已经是中国区预选第四，只差一步就能拿到LCQ资格。小说中的iG如果此前已经因为主角从Tour2升入S级，那么到9月比现实iG更强是连贯结果。

最小路径：

1. 在地区预选把现实0:2负VG翻掉，拿第三进入LCQ；
2. LCQ进前二；
3. TI首年5-8名。

### 优势

与P2相比，**资格赛阶段少一层跃迁**：现实iG本来就离LCQ只差一个系列赛。

### 代价

这个优势是建立在春季已经改写iG升级结果、并阻断现实fy入队路径之后，不是“零改历史”。

**资格赛阶段P3优于P2；全年总改动差距没有表面那么大。**

# 节点7：TI后为什么自然离开/重组

## P2：最大新风险——Aster体系与合同

现实Xwy/一在2022年11月13日从Aries转入Team Aster，接替退役的Ori。

如果小说里的主角比现实Xwy更强、甚至第一年打进TI并表现出色，则Aster主队会更有理由想把他留下/提拔，而不是更少。

因此P2不能写：

> TI打完 → 主角说我要和Ame打 → 第二天自由组队。

必须正面处理：

- Aster是否拥有合同/注册权；
- 主队是否提出晋升邀请；
- 主角为什么拒绝一个现实中刚拿TI11第四的成熟强队；
- 新队/新俱乐部是否愿意承担转会成本；
- Aster是否愿意放人。

这反而可以成为一个很好的职业选择节点：主角第一次不是“有队要我就去”，而是已经有资格选择自己真正相信的阵容。

**剧情价值高，但现实手续成本不可忽略。**

---

## P3：iG重建天然提供离队口

现实iG在2022年底大规模重建，flyfly、fy、JT-、Oli等均离开，只有Emo等进入新结构。

如果小说iG首年取得亮眼但未夺冠成绩，TI后阵容结束并不突兀。

但仍不能假设iG主动不要一个世界级新人。更自然的原因是：

- 主角希望从4正式转3；
- iG的下一阶段规划未必愿意围绕一次大转位重建；
- 双方友好结束，而不是“队友变菜所以主角跑路”。

**P3在离队手续/组织叙事上明显比P2干净。**

# 节点8：为什么Ame也会主动认可并愿意与主角组队

这个节点不再使用“主角证明自己不是唯一答案”的逻辑。Ame需要判断的是：

> 和这个人、以及这套五人结构一起打，我赢TI的概率是不是更高？

## P2

Ame看到的是一个**已经在正式职业比赛长期打2并达到世界级强度的人**：

- 6月已经正面对过LGD；
- 夏季和TI预选持续进化；
- 如果最终打入TI深轮次，竞技信誉完全成立；
- 主角未来与Ame只是重新设计1/2资源和英雄职责，不需要先证明自己能胜任一个新位置。

最大的组队问题变成真正的强队问题：

- 1/2谁吃哪种资源；
- 哪些英雄/版本可以双核同时贪；
- 哪些版本主角主动、Ame后置；
- 哪些版本反过来；
- 3/4/5如何提供空间与连接。

**Ame选择P2主角的竞技理由最容易成立。**

---

## P3

Ame认可主角作为4号位世界级新人并不难；真正困难的是：

> 为什么他愿意把争冠队的3号位交给一个正式职业生涯主要打4、刚准备转3的人？

即使主角Rank/系统里一直保留3号位，这仍不同于顶级职业3号位履历。

如果Faith_bian退出后市场上还有Xxs、Chalice等成熟3号位，Ame及新队管理层需要非常强的理由押注主角转位。

可补救方式只有两种：

1. TI11后留出足够休赛期，通过高水平训练赛证明主角的3号位已经达到争冠强度；
2. 主角在2022就有大量可验证的3号位训练/临时比赛样本，而非TI后才起意。

这两种都可写，但都增加了一层“先证明新位置”的门槛。

**这是P3在终局组队上的最大弱点。**

# 八节点横向结论

| 节点 | P2：Aries 2→长期2 | P3：iG 4→长期3 |
|---|---|---|
| 1. TI10后三个月成长 | **自然** | 需从主2增加大量4号位样本 |
| 2. 职业圈认可 | **高分中单路径直接** | iG对4号位证明要求更高 |
| 3. 试训理由 | **现实确有中单试用/更换** | 需插入Frisk→fy之间 |
| 4. 第一场职业失败 | 自然 | 自然 |
| 5. 第一次正式对Ame | **现实6/24直接存在** | 需先改写升S |
| 6. TI11资格 | 现实5-6，需跨iG+VG+LCQ | **现实iG第4，离LCQ更近** |
| 7. TI后离队 | Aster主队会强留，需转会处理 | **现实大重建，接口自然** |
| 8. Ame愿意组队 | **已证明世界级2即可直接评估** | 必须额外证明转3达到争冠强度 |

## 当前总判断

经过八节点压力测试，**P2首次取得整体领先**。

不是因为中单比三号位更重要，也不是因为“主角应该走个人英雄路线”，而是：

> **P2用同一个职业身份完成了从路人→职业→对阵Ame→TI→最终组队的完整闭环；P3则在首队进入和最终转位两端都各需要一次额外解释。**

P3仍有两个明显优势：

1. 地区预选离LCQ更近；
2. TI后从iG离开的组织接口更自然。

但P3要同时解决：

- 为什么iG选新人4而不是沿现实Frisk/fy路径；
- 为什么主角能让iG提前升S；
- 为什么最终要从已经打成世界级的4转3；
- 为什么Ame愿意在争冠队里押注这个位置转换。

这些不是任何一条都不可解，而是**同一路线连续叠加**后，作者手开始比P2更明显。

# P2尚未解决的两项硬问题

如果下一步考虑锁P2，必须先完成最后两项审查：

## A. Aster合同/主队晋升问题

现实Xwy的路径就是Aries → Team Aster。小说主角越强，这个吸力越大。

需要查：
- 2022—23 Aster/Aries公开转会与合同语境；
- 中国Dota当时类似青训/二队选手向外转会的真实案例；
- 是否可以通过新俱乐部购买、交换或合同到期等方式自然离开。

## B. 主角2 + Ame1的竞技化学反应

不以“谁更需要谁”为问题，而要建立：
- 两人英雄池的互补/重叠；
- 对线期到中期谁承担第一轮发动；
- 双核经济需求冲突时如何由阵容解决；
- 不同版本下核心职责如何轮换；
- 3/4/5应该选择哪种类型才能把双核连接起来。

在这两项完成前，P2是**领先路线，不是锁定路线**。
