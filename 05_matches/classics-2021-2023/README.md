# TI10后两年：经典对局与职业比赛素材库

更新：2026-09-15。Batch 012阶段研究成果；合入状态以GitHub main及PR为准。

这批资料用于找到值得写的比赛，而不是给普通操作补上夸张解说。先看真正发生过什么，再挑适合本书人物和当期版本的戏；不把真实名场面原封不动分配给主角。

## 已收集到什么

范围为北京时间2021-10-18至2023-10-30，略超过严格两年，以完整覆盖TI12。共取得**31个赛事/联赛数据集、3329场不重复比赛索引，62组系列赛、171局详细数据**，总比赛时长约115.4小时。其中2021年6局、2022年111局、2023年54局。另补利雅得2023缺失的15局身份索引，其中总决赛4局有十人英雄对应；这15局不冒充完整解析数据，也未混入上述3329/171统计。

这是有较广覆盖、已完成两轮补充的素材库，不是全球全部赛事清单，也不是171局已经逐秒核片。当前**完整观看录像0局、局部片段观看0局，自行解析这些比赛的原始回放0局**；读取了入选比赛的第三方解析数据，并对重点案例做了数据与公开复盘的交叉研究。第二轮浏览器连接失败，未看见比赛画面。TI10 G5以前已做的原始回放提取另存，不计入这里。

## 一场比赛具体保存了什么

| 信息 | 已保存字段 | 不能据此直接推出的内容 |
|---|---|---|
| 身份与来源 | 比赛ID、赛事ID、双方队伍ID、当期编辑队名、原API队名、时间、原数据哈希与来源URL | 现在平台显示的队名/昵称不一定是当年的名字 |
| 阵容与BP | 十人账户ID、英雄ID和中文名、阵营、选禁顺序、BP计时（有缺口）、技能升级数组 | 玩家当前昵称、算法推断的分路不等于当期实名或战队职务；升级数组不提供精确学技能时刻 |
| 终局状态 | 等级、KDA、补刀反补、净资产、GPM/XPM、伤害治疗、装备/背包/中立槽、部分永久增益 | 终局装备不能倒填到20分钟；末帧物品变动不能代表整局表现 |
| 经济进程 | 双方经济/经验差分钟序列；分人原始`times/gold_t/xp_t/lh_t/dn_t` | 分钟采样不是连续记录；不把分人`gold_t`直接改称当前现金或可支配买活钱 |
| 装备进程 | 完整购入日志；阅读卡摘出关键大件 | 买下、信使运送、装备在身、可使用是不同事件；不由购入日志擅自补送达时刻 |
| 战斗 | 击杀日志、买活、技能使用和目标汇总、伤害来源、平台团战聚类 | 汇总不是逐次施法顺序；击杀者不是唯一贡献者；团战聚类会漏掉重要交锋 |
| 地图 | 建筑/肉山/神盾日志、符、眼位坐标与放置/消失日志、分路位置样本 | 有眼不等于全队看见了某人；坐标不是完整战争迷雾；不知道当时玩家屏幕在看哪 |
| 缺口 | 各字段分别标记有值、源字段缺失、源为null、源为空 | 空数组不能默认没有发生；没有记录不代表没有暂停、买活或沟通 |

171局均有阵容BP、经济/经验曲线、目标日志；1710个人次均有非空购入日志。169局有非空BP计时和团战聚类。暂停字段仅1局有非空记录，其余缺失或空，故**不能用统一的视频偏移量定位全部比赛**。

`patch_precision.candidate`目前全部是**依据官方发布日期推定的版本候选**，不是已经核定的赛事客户端版本。OpenDota数字`patch`通常只对应大版本，不能凭它补出字母补丁；解析器`version`更不是游戏版本。本库没有下载当前装备数值替代历史数值。

## 时间和归属的读法

- 日期统一给北京时间，同时保存UTC；“当地7月28日”可能已是北京7月29日。
- 日志的`time`按平台给出的游戏秒数保存；负数为开局前阶段。录像时间必须现场找到游戏时钟，再考虑暂停和剪辑。
- 天辉经济差为正表示天辉领先，为负表示夜魇领先。“胜方最差样本”只是最终胜方的最低分钟差，不等于这局真正最危险的时刻。
- `objectives`中带`dota_unknown`的遗迹销毁可能是GG结束后的终局事件；不能据此描写某英雄最后一下拆家。日志偶有比`duration`晚1秒的事件，保留原值，不伪造精度。
- 队伍ID也可能随队伍更名、重组延续。本次把RNG、Entity、2022 EG/2023 Shopify等当期称呼与平台现名分开；没有把这些记录合并成不变的十人阵容。

## 还缺什么

最重要的缺口是**玩家视角、当时可知信息、连续动作和当期机制参数**。这些应在选中具体情节后核验对应片段，不让整本小说等待115小时录像全部看完。两轮重点卡已经列出要看的游戏时段与待回答问题。

TI11中国区预选42局已并入，并与Spectral的42个ID、19组系列及赛事赛程交叉核对。利雅得2023的15局API详情仍缺，只有局部替代资料；亚运会与部分地区联赛尚未覆盖。17局中国预选的合计人头在两站有差异，原值均保留，不擅选一个当转播比分。具体状态见[来源记录](sources-and-gaps.md)。

## 复现

Python 3.12标准库，无额外依赖。使用`python -B -X utf8 07_sources/classic-corpus/collect.py --cache <本地缓存目录>`读取或补取公开数据；加`--offline`只读现有缓存。脚本会重新生成索引、数据档和系列赛数据卡，**人工研究卡、网页事实摘录及来源记录不会被覆盖**。再运行`validate.py --cache <本地缓存目录>`核对数据及交叉来源；它不把来源间的已知比分分歧伪装成一致。原API响应留在仓库外的`dota-classics-cache`；仓库内保存派生资料及原始哈希。
