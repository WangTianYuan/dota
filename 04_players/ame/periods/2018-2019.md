# Ame时期档案：2018—2019 PSG.LGD争冠期

ID: player:ame:period:2018-2019
类型：F/Q/O/I分离

## 职业处境

2018春季LGD进入世界争冠序列，核心阵容逐步稳定为Ame / Maybe / Chalice / fy / xNova；取得EPICENTER XL、MDL长沙等冠军，并在TI8获得亚军。2019大体延续同一五人，TI9获季军。

本页不把2018、2019完全视为相同状态；它们共同构成“年轻Ame第一次连续作为世界级争冠核心”的研究阶段，后续可按具体赛事继续拆细。

## 游戏内：资源并非固定剧本

### F/Q：Ame与Maybe会根据英雄调整职责

2018 DAC前Maybe被问到自己与Ame如何分配打架/发育任务。他的回答指向按英雄和阵容调整，而不是固定“Maybe打架、Ame刷钱”。

来源：https://ol.gamersky.com/news/201804/1032082.shtml

### I：小说使用

可以写年轻Ame已经习惯与强势中单共享核心资源，需要根据阵容让渡节奏或承担后期；不要把他塑造成“只能四保一”的选手。

## 团队关系与氛围

### Q：2018公开采访

Maybe说游戏外大家关系较好，会一起吃饭、开玩笑；Chalice也多次把“fy吸血”等粉丝梗解释为团队需要。

来源：
- https://dota2.17173.com/news/04032018/170249288.shtml
- https://www.sohu.com/a/231943299_537985
- https://www.sohu.com/a/334887605_120099889

### 反例边界

“关系好”不能推导成没有争执，也不能推导成所有人私下都是最亲密朋友。公开采访主要能支持：他们愿意在公开场合互相调侃，并把资源牺牲理解为团队分工。

## 版本适应：这一代选手已经会主动研究

2018五月版本调整后，Maybe公开说队伍没有及时一起讨论版本变化造成的影响；Chalice也提到版本更新、缺少训练对手影响状态。

来源：
- https://games.sina.cn/gz/dt/2018-05-18/details-iharvfhv2414198.d.html
- https://www.sohu.com/a/231943299_537985

这是一条重要写作证据：2018的顶队已经知道版本讨论和训练质量的重要性；主角的系统不能靠一句“别人不研究版本”获得优势。

## 公开表达：短、干、会接梗

2019 TI9采访中Ame会用简短回答应对网络评价和热点话题，也会以“模仿DOTA上帝”等方式接ana一号位Io的梗。

视频/报道入口：
- https://www.bilibili.com/video/BV1F4411R7tJ/
- 相关媒体采访需继续补一手文字原稿。

### 写作建议（I）

年轻阶段可以让Ame：
- 不主动发表长篇理论；
- 熟人语境下会接梗、吐槽；
- 对陌生采访可能只答核心句；
- 不等于社恐、木讷或没有观点。
