# DOTA2直播与视频热度：TI10（2021）—2026

ID: ecosystem:dota-streaming-video-heat-2021-2026
更新时间：2026-09-13
用途：判断小说中主角在不同阶段开直播、被OB、被切片、参加平台活动以及直播商业价值的现实性。

## 先给结论

不能简单写成“TI10之后DOTA越来越凉”。更准确的结构是：

> **2021/TI10全球与中文社区情绪峰值 → 2022—2023赛事观看明显降温 → 2024企稳 → 2025—2026全球TI观看恢复；中国社区总体仍偏小众，但核心用户黏性强，且对中国队/Ame是否深跑高度敏感。**

对小说最重要的结论：

1. **2021末—2022初，主角偶尔直播完全合理。** DOTA2仍是中国传统直播平台的重要端游品类，B站已经是DPC正式直播平台；但新人从零靠直播自然长成大主播并不是最佳入圈路径。
2. **更可信的早期曝光链是：高分Rank反复遇到头部主播/职业选手 → 被OB或同局直播 → B站切片/录像传播 → 平台活动或主播熟人局 → 职业试训。**
3. **直播应该是曝光放大器，不是主角职业前的主要收入来源。** 主角可以无固定时刻地开播，但不需要为了直播每天固定6—8小时营业。
4. **成为职业选手后，比赛成绩决定直播/视频价值。** 如果2022 Aries打进TI、主角是爆发型新人，平台邀约、录像切片、直播间关注增长都会非常自然。
5. **2024以后“直播间本身”相对不再是唯一入口，视频/切片/二路解说/社区共播的重要性更高。** 这与整个游戏直播行业向B站、短视频和多平台内容迁移一致。
6. DOTA中文生态更适合描述成**“体量不如一线大众电竞，但核心观众密度、付费/互动意愿和熟人社区感较强”**，而不是“没人看”。

## 一、为什么不能用一个“热度值”横跨所有平台

中国直播平台长期使用“热度、人气、累计观看、播放量”等不同指标，不能与Twitch/YouTube意义上的并发观众（CCV）直接比较。

本文件分四类代理指标：

1. **全球大型赛事直播峰值/观看时长**：优先Esports Charts；注意其明确排除中国直播平台数据。
2. **中国直播平台内容生态**：赛事版权、官方直播渠道、平台行业变化。
3. **B站视频与赛事账号**：代表录像/切片/中长视频的传播能力，不等于实时直播CCV。
4. **主播/社区信号**：头部主播、共播、礼物/互动、从业者公开评价，只用于理解生态，不当作总用户规模。

### 解释

这条曲线更像：

> **TI10异常高峰 → 两年均值回归/赛事结构变化 → 2024触底企稳 → 2025/26恢复。**

不能据此说DOTA重新变成大众第一梯队。Esports Charts指出TI2023、TI2024都没有进入当年所有电竞赛事峰值观看Top10；但TI仍然是DOTA绝对的超级事件，而且2025/26已经明显反弹。

### 共播越来越重要

Esports Charts对TI2025的统计显示，community/co-streaming贡献了接近**49%观看时长**；此前多届大致在34%—44%区间。官方主频道份额下降，不代表观众全部消失，更多观看被分散到主播/二路/社区频道。

来源：https://escharts.com/news/international-2025-most-co-streamed-ti

**小说含义：**“某个顶级主播在直播时排到主角”“比赛被多个主播二路解说”“主角高光从直播间被切成视频”在2021以后只会越来越自然。

## 三、中国直播生态：2021仍强，2022后垂类平台进入存量期

### 1. 2021：DOTA仍是直播平台的重要端游品类

小葫芦2021年8月一周游戏直播榜中，MOBA前三是《王者荣耀》《英雄联盟》《DOTA2》，DOTA2仍处于传统游戏直播的重要位置。

来源：https://www.199it.com/archives/1306166.html

艾瑞2022电竞行业报告（回看2021）也指出，英雄联盟和DOTA2在各自全球总决赛期间都出现明显观看热潮，官方直播间弹幕量成倍增长。

来源：https://www.idigital.com.cn/nfs/reports/c95cea874ff6cb8cd43f/40e2697b6515ba4222f4.pdf

### 2. 2021 DPC已经同时进入斗鱼/B站，之后也有虎牙

完美世界官方公告：

- 2021年1月DPC中国定级赛：DOTA2客户端、斗鱼、哔哩哔哩全程直播；
- 2021年春季DPC部分官方预告列出斗鱼、虎牙、哔哩哔哩；
- 2021年12月DPC官方采访多次直接引导观众“在哔哩哔哩直播收看”。

来源：
- https://www.dota2.com.cn/article/details/20210107/219171.html
- https://www.dota2.com.cn/article/details/20210412/220042.html
- https://www.dota2.com.cn/article/details/20211207/220168.html

**小说含义：**2021末主角在B站/斗鱼偶尔直播、被主播OB、或通过DPC相关平台生态被用户认识都不违和。B站并不是后来才突然进入DOTA生态。

### 3. 2022：游戏直播行业从增量转向存量，用户向综合视频/短视频迁移

2021→2022并非DOTA单独发生变化，而是中国游戏直播平台整体进入流量压力期：

- 行业报道引用《2021游戏直播行业洞察报告》：虎牙游戏主播数从301.6万降至234.8万，斗鱼从192.6万降至159.6万；与此同时B站游戏主播数量增长到162.4万。
- TalkingData 2022白皮书：垂直游戏直播平台流失用户中，**45.4%迁往短视频平台**，19.1%不再使用游戏直播类平台。

来源：
- https://finance.sina.com.cn/chanjing/gsnews/2022-05-20/doc-imcwiwst8539361.shtml
- https://www.tmtpost.com/6283000.html

这意味着小说里不应该假设“2022以后曝光=必须经营一个斗鱼大直播间”。视频、切片、二路、B站动态、短视频平台都越来越重要。

### 4. DOTA赛事版权仍有商业价值

虎牙2021年11月与ESL签了2022—2023两年中文独家直播版权，覆盖DOTA2/CS:GO/星际争霸2等赛事。

来源：
- 虎牙官方：https://blog.huya.com/news/33097
- 36氪：https://www.36kr.com/newsflashes/1490206124943235

到2025，虎牙在SEC年报中仍把自制的**DOTA2 Immortal Cup（不朽杯）**列为平台当年“最受欢迎”的自制电竞/游戏活动之一。

来源：https://www.sec.gov/Archives/edgar/data/1728190/000110465926048944/huya-20251231x20f.htm

因此DOTA不是2022后从直播商业体系里消失，而是从大众增量赛道逐步变成更依赖核心受众、明星选手和赛事节点的成熟品类。

### 核心观察

**B站DOTA内容不是稳定均匀消费，而是强事件驱动。**

- 中国队/Ame深跑时，比赛长录像也能获得数十万至近百万级播放；
- 没有中国队的外国队决赛仍有人看，但播放量明显更低；
- “历史名局、情怀、明星选手、主播反应、复盘/切片”能获得超出普通常规赛的长尾播放。

这对小说非常有价值：

> 主角不需要先有几十万粉丝。只要他在高分局与Zhou/Maybe/Ame等高关注人物产生真实交集，他的某一盘、某个高光、某段对话就可以先通过别人的直播和B站切片被看见。

2023年TI12，B站官方动态宣布全程直播，并显示约**21万人预约**赛事。到2026年，`哔哩哔哩刀塔2赛事`账号已经是百万关注量级；DOTA2还参加了Bilibili World 2026线下展台活动。

## 五、“小众但核心用户深”比“已经没人看”更接近事实

一篇使用小葫芦2021数据的电竞赛事研究指出：KPL在五个平台的赛事直播与短视频声量远高于多数项目，但其礼物价值仍低于**开播人数最少的DOTA2**。这不是说DOTA商业规模比KPL大，而是说明较小的DOTA直播群体可能具有更高的核心用户付费/互动密度。

来源：https://pdf.hanspub.org/ecl2025142_642313110.pdf

2025年职业选手Monet在公开直播切片中也直言DOTA2“比较小众、热度不高”，不建议把做切片/直播本身当成轻松挣钱方式。这是单个选手的主观判断，但与“成熟小众品类、头部集中”的结构相符。

来源：https://www.bilibili.com/video/BV1zPV2zVE5Q/

因此故事中更合理的是：

- 有一批很懂游戏、会认高分ID、对职业选手熟悉的核心观众；
- 热度集中在TI、中国队、Ame/Maybe/fy等明星、版本大更新和大型第三方赛事；
- 普通新人单独开播不一定有人看；
- **一旦新人被头部圈子反复“采样”，核心社区传播速度可以很快。**

## 七、按年份给小说的直播策略

### 2021-10 ～ 2021-12：可以开，但不要把主角写成“新人主播起号”

推荐：

- 主角原本可以有一个很小的B站/斗鱼账号，甚至只是偶尔开播；
- 没有固定直播合同和时长KPI；
- 直播画面简单，重点是Rank本身；
- 真正传播来自“排到谁”——Zhou/ZSMJ/职业选手/主播的直播间比主角自己的直播间更重要；
- B站切片、录像、主播反应视频开始让ID在核心圈出现。

**不推荐：**系统出现一个月就靠个人直播积累大粉丝量、礼物收入解决生活问题。

### 2022春：直播可以辅助入圈，但职业样本权重高于直播粉丝

推荐：

- 高分Rank重复出现后，可以有几百/几千稳定关注者，具体数量后置；
- 平台娱乐杯、OB选人局、与职业选手组排的曝光价值高于单纯直播时长；
- Aries试训理由仍应是**游戏水平与圈内口碑**，不能是“粉丝多所以签”。

### 2022加入Aries后：职业优先，直播成为附属资产

- 战队训练/正式比赛优先；
- 偶尔直播、平台活动、赞助商要求都自然；
- 如果主角在S级/TI预选/LCQ打出名场面，直播关注量会随成绩跳升；
- B站切片、赛后采访、OB评价会比主角自己天天营业更有效。

### TI11后：如果首年深跑，直播商业价值才真正成立

此时可以合理出现：

- 平台签约邀约；
- 休赛期高热直播；
- 和Ame/Maybe/XinQ等同局带来的高传播；
- B站UP主做复盘/高光；
- 主角本人偶尔直播就有明显观众规模。

但即使成为明星选手，也不需要转成“职业选手兼全职主播”。

### 2024—2026：视频/切片/共播比“单一直播间经营”更重要

DOTA受众越来越通过：

- 赛事官方直播；
- 二路共播；
- B站长录像/复盘；
- 短视频高光；
- 职业选手休赛期直播；

共同消费内容。主角的媒体价值应该是跨形态的，而不是只用“直播间人气值”衡量。

## 八、对当前canon的直接建议

### 建议继续保留

> **“直播只是曝光放大器，不是主线。”**

并细化为：

> **主角早期的第一传播渠道不是自己的粉丝，而是DOTA核心社区对高分ID的交叉传播：头部主播直播间 → OB/组排 → 切片 → 平台活动 → 职业圈。**

### 可以增加的真实感节点

1. 主角自己直播间只有少量人，但Zhou直播时排到他，弹幕开始认识ID；
2. B站有人剪“这中单最近怎么老在高分局出现”；
3. 某次平台/OB活动后，搜索主角ID能看到几条几万播放的切片，但本人账号粉丝并不夸张；
4. 加入Aries、打赢S级队伍后，旧切片被重新翻出来；
5. TI11后直播价值出现量级跃迁。

这种路径比“主播粉丝一路线性增长”更符合2021—2026 DOTA中文生态。

## 九、证据边界

- Esports Charts不含中国平台，不能当作全球含中国总人数。
- B站播放量是累计播放快照，不是独立用户，更不是并发观众；老视频拥有更长累积时间。
- 同届TI不同队伍进入决赛对中国播放量影响巨大，所以不能只按年份比较。
- 中国直播平台的“热度/人气”算法长期不透明，不使用未经定义的热度值做硬同比。
- 单个主播/选手对“热度”的公开评价是人物观点（Q），不是行业统计事实。
