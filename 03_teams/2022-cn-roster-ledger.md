## 证据口径

## PSG.LGD

2021 TI10后至TI11保持核心五人：Ame / NothingToSay / Faith_bian / XinQ / y`，教练xiao8。2022第一、第二Tour中国区长期处于顶级；7月Riyadh Masters夺冠，8月Arlington Major亚军，TI11止步5-6。

**结论：2022赛季中没有自然选手空缺。** 为了主角提前加入而强拆这套仍有世界冠军竞争力的阵容，蝴蝶效应成本极高。

## Team Aster

**结论：不适合作为2022春夏第一队默认候选。**

## Xtreme Gaming

2021-11-22新阵容初始为J / Paparazi / Srf / Pyw / Dy；2022-01-06 J和Srf转不活跃，Lou和old eLeVeN加入。随后一直以Lou / Paparazi / old eLeVeN / Pyw / Dy为2022核心。

1月变动发生得过早：主角TI10后仅训练约两个半月，很难在不强行加速的情况下取代Lou或old eLeVeN。之后到TI11前阵容基本稳定。

## Royal Never Give Up

第一Tour阶段：圣子华炼 / Somnus / Chalice / FelixCiaoBa / xNova。Chalice在1月采访中明确提到队伍仍在磨合沟通、互相打法和阵容理解。

2022-04-27 Kaka加入；2022-05-04 Ghost加入，形成Ghost / Somnus / Chalice / Kaka / xNova，并以该阵容打第三Tour和TI11。

**现实可插入窗口：4号位最明显。** FelixCiaoBa离开主力后，现实答案是Kaka；小说若主角此前通过Rank、OB活动、试训积累足够认可，可以把“RNG选择Kaka还是选择18岁新人”作为一个高强度但可解释的蝴蝶效应节点。代价是会改写Kaka的2022轨迹。

## EHOME

2021末组建：shiro / 7e / zeal / planet / zzq。2022-03-20，7e被Echo替换。此后以shiro / Echo / zeal / planet / zzq完成赛季。

**现实可插入窗口：2号位最清晰。** 3月真实发生中单更换，且EHOME已经拥有S级席位。主角若最终定位中单，这是一条几乎不需要额外制造“为什么突然有空位”的路径。

代价：第一职业队整体年轻，主角获得世界大赛经验的速度取决于小说改写后的成绩；TI11后shiro、planet转入LGD，EHOME也发生重构，主角离队的现实支点很好。

来源：https://liquipedia.net/dota2/EHOME

## Vici Gaming

2021-11-19新阵容：Erika / Xm / Irving / Yds. / 起风了。2022-02-22 Irving离队，2022-03-18 Yang回归；夏季之后又更换3/4/5形成TI预选阵容。

**现实可插入窗口：3号位非常清晰。** 2月22日至3月18日本就存在实际更换窗口；小说可让VG在“召回Yang”之外试训主角。VG当时仍在S级，能让新人直接进入一线联赛。

第二个窗口在8月的3/4/5重构，但太晚，不适合作为首支职业队。

来源：https://liquipedia.net/dota2/Vici_Gaming

## Invictus Gaming

TI10阵容为flyfly / Emo / JT- / Kaka / Oli。2021-11-21 Kaka合同到期离队，Fade加入；第一TourS级仅第7，降到第二TourA级。2022-05-14 fy加入，第三TourA级主力为flyfly / Emo / JT- / fy / Oli，最终A级第二。

**现实可插入窗口：4号位。** 主角赶不上11月Kaka离开后的第一轮补位，但iG第一Tour从TI10世界第四跌到降级后，1月底至春季天然存在“是否继续用Fade/是否试新人”的竞技压力。现实到5月才由fy进入，因此小说可将这个变化提前。

优点：俱乐部正规、队友有TI10世界第四经验，能够强烈体现“天梯能力≠职业能力”；缺点：第二Tour必须从A级打起，若希望6月就进S级，需要主角帮助iG把现实第三名改写成前二。

来源：https://liquipedia.net/dota2/Invictus_Gaming

## Aster.Aries

2021末主力：Ulu / White丶Album / 生死 / TK / RedPanda。2022-05-18中单“一”加入，White丶Album离开；第三Tour升入S级并最终第5。8月4号位又发生调整。

**现实可插入窗口：2号位（5月）。** 优点是Aster体系正规、第三Tour可立即打S级；缺点是主角直到5月才进入正式一线，前半年的职业兑现偏晚，除非前面OB/杯赛内容足够有强度。

来源：https://liquipedia.net/dota2/Aster.Aries

## Dandelion Esport Club

2022-03公开海选第一进入第二TourA级，随后7-0第一升S级；第三TourS级1-6垫底。

**研究意义大于默认首队价值。** 它证明“海选→一个Tour横扫A级→下一Tour直接S级”现实存在，但也证明同一阵容到更高层级可能迅速暴露问题。小说无需把主角塞进真实DEC，也不应因为其A级7-0就默认这套阵容具备TI级上限。

来源：
https://liquipedia.net/dota2/Dandelion_Esport_Club
https://liquipedia.net/dota2/Dandelion_Esport_Club/Played_Matches

## Team Fusion

2022年5月由圣子华炼 / White丶Album / Flyby / ponlo / XCJ组成，从第三Tour公开海选第一进入A级。

**这是“已有职业经历的知名选手临时/重新组队打公开海选”的直接现实原型。** 因而小说中Maybe、Chalice、OB圈或其他职业选手参与类似海选/临时赛的文化逻辑可以成立，但具体谁在什么时间参加仍需逐人核实。

Fusion最终A级第6，说明“名字好看”并不等于临时队天然有团队战力。

## 下一步

对VG、EHOME、iG、RNG四条高价值线继续查：
1. 真实换人前后的战绩与公开原因；
2. 当时替换选手的可用候选；
3. 队伍内部谁负责指挥/BP/带新人；
4. 主角进入后能否在不凭空提升四名队友的情况下合理进TI11；
5. TI11后离队是否自然，以及和Ame重组时会带走哪些关系资产。
