## 2. Batch 011最重要的已锁结论

### 系统

- 极简HUD + 深度训练/模拟空间；
- 工具化中性，无陪聊人格；
- 主角主动调用为主；
- 正常时间、正常训练量、正常睡眠恢复；
- 睡眠只巩固已学内容；
- 历史模拟稀缺、无读档回滚；
- 赛后反馈给事实/异常/问题，不给最优答案；
- 无综合战力值、经验值、任务币、属性点；
- **真实天梯/训练赛/正式比赛过程中系统完全退出，不记录、不提醒、不报点、不统计。**

### 主角成长

- TI10赛后人物欲望先产生，系统后出现；
- 第一阶段从中路具体问题进入，但不能把普通高分常识当大发现；
- 二号位需要学习“缺哪条信息、什么时候值得问队友一句”，不能全知全图；
- 早期可以快速变强，不设人为成长速度上限；
- 防的是无代价全能，不是防天才；
- 长期成长是波浪式：版本、对手和团队不断提出新题。

### 入圈/直播

- Zhou是主要天梯熟脸，ZSMJ第二；
- 不连续写很多盘反复相遇，一盘代表性对局里一句“最近老排到他”即可压缩前史；
- 先被高分天梯/主播观众认ID和切片，再开自己的直播；
- 直播首先是打游戏，不是课堂；
- 公众认知升级：讲清因果 → 提前判断 → 研究冷门/新打法。

### 技战术与Meta

- 现实资料是输入/校准，不是创新硬上限；
- 所有创新先过版本门；
- 优先研究“天梯强、职业少见”的采用障碍；
- 冷门英雄必须有条件、职责、代价和反制；
- 主角可以形成强科研优势：
  **发现Meta → 职业化 → 预演复制/针对 → 提前准备反Meta。**
- 后期允许Meta / 反Meta / 反反Meta多层博弈；
- 长期领先在于更早理解Meta为什么成立、会怎样死亡。

### 中文叙事

游戏正文默认使用中文英雄/装备/机制/社区术语；英文主要留给ID、队名、外国原话和研究检索。
