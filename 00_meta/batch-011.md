# Batch 011：系统UX、训练循环、早期成长与Meta科研

## 本批目标

本批从“系统是先进个人训练基础设施”的既有方向出发，完成四组高耦合问题：

1. 系统在正文里如何出现、训练、反馈、睡眠巩固、历史模拟与权限开放；
2. 系统如何严格退出真实天梯/训练赛/正式比赛，不成为隐形助手；
3. 主角在TI10后前几周怎样从高分玩家成长为具有职业潜力、科研能力和公开表达能力的二号位；
4. 小说如何处理原创技战术、冷门英雄、版本Meta、直播教学与中文Dota术语。

本批不锁具体章节、具体对局台词、具体天梯分数、直播平台或最终比赛细节。

## 一、系统UX：已确认

### 1—6：基础使用体验

- **1B**：现实极简HUD + 深度训练/模拟空间；
- **2A**：系统人格工具化、中性，不承担陪聊/吐槽角色；
- **3C**：普通使用由主角主动调用，重大节点/瓶颈/稀缺机会才主动提示；
- **4D**：现实时间正常、训练量正常，睡眠只做已经学习内容的整理/巩固；
- **5B**：历史模拟门票稀缺，每次完整进入消耗一次，不可暂停读档/回滚；
- **6C**：反馈以客观记录、比较、异常和问题为主，不直接输出最优战术答案。

核心成长公式：

> **顶级天赋 × 正确方法 × 巨大训练量 × 高质量反馈 × 时间。**

核心限制：

> **系统不减少成为顶级职业选手所需要的训练量，它减少的是大量“练错、想错、复盘错、长期不知道自己为什么错”的时间。**

系统能力不会无限升级；主角真正长期增长的是“使用系统、提出问题、迁移规律和设计实验”的能力。

### 7—15：训练、面板、权限和信息边界

作者确认当前基线：**7B / 8B / 9C / 10C / 11B / 12C / 13C修订 / 14C / 15C**。

关键结论：

- 不设置“对线87 / 大局观92”式综合能力值；状态主要显示可观察样本、趋势、稳定性、异常和样本不足；
- 不设置经验值、任务币、属性点或商城；高级工具通过主角证明自己能正确使用已有工具而开放；
- 历史模拟是阶段性迁移考试，系统只提供少量与当前问题相关的候选历史节点；
- 普通训练空间能高精度控制英雄、等级、装备、冷却、血蓝、兵线、视野等局面变量并重复训练，但不能生成无限真实的完整职业五人对练；
- 赛后报告只筛少数高价值节点：客观发生了什么、当时可见信息、主角做了什么、样本异常/模式、一个问题；
- 深度训练要求安全静止状态，现实声音、触碰、闹钟和危险可立即打断；
- 睡眠只重组/再激活已学材料，可以提示关联样本，不直接生成新战术知识；
- 系统界面使用“研究目标 / 阶段验证 / 异常样本 / 工具权限 / 历史模拟资格”等语言，不采用传统MMO任务结算语言。

### 13C修订：真实比赛中系统完全退出

这是本批重要修正。

**真实天梯、训练赛和正式比赛进行中，系统不记录、不提醒、不报点、不计时、不维护战场状态，也不替主角统计“辅助消失多少秒”。**

主角必须靠自己的：

- 观察；
- 记忆；
- 操作；
- 沟通；
- 临场判断。

高精度系统处理只发生在比赛结束后、主角主动进入复盘时。系统可以使用主角合法获得的录像/回放/比赛记录，并严格区分：

> **当时主角理论上可见的信息 / 主角实际行为 / 赛后录像中的全局事实。**

系统不读取其他队未公开训练赛、电脑、语音或秘密战术。

详细规则：`06_story/system-training-baseline.md`。

## 二、系统出现后的早期成长：已确认结构

### 16：功能显露——D+B组合

- 第一次以TI10历史模拟形成强开场；
- 之后系统功能分阶段显露；
- 不用一次性说明书把全部功能告诉读者。

### 17：第一阶段训练——D

从具体中路问题切入，并逐渐抽象成信息、兵线、行动窗口、资源和地图问题。

重要修正：主角在系统出现前已经是高水平玩家，不能把“六分钟神符要辅助”“辅助消失要小心”“推线可以游走”等普通高分玩家常识包装成大发现。

真正值得研究的是：

- 哪些条件决定常识成立；
- 哪些变量只是相关，哪些才是主因；
- 一次结果到底在几十秒前还是更早就被资源交换决定；
- 同一规律能否迁移到不同英雄和目标；
- 主角在实战中缺哪条信息、是否值得向队友主动问一句。

### 18：成长速度——短期C、长期D，但不设人为速度上限

原选择为“短期快速兑现后第一次撞墙，长期波浪式成长”。随后进一步确认：

> **不把‘成长不能太快’作为硬限制，真正要防的是无代价全能。**

Dota团队复杂度足够支撑长期故事。只要训练、天赋、真实验证和版本条件成立，主角可以很快达到顶级中单的部分甚至多数个人维度，也可以很快扩英雄池、提高版本理解。

后续难度来自五人执行、队友状态、阵容职责、对手研究、版本变化、长系列赛和团队化学反应，而不是人为压主角变强速度。

### 19：第一次自己开播——C

传播链采用：

> 高分天梯持续变强 → 反复撞到Zhou/ZSMJ/职业与主播 → 观众先认ID/出现切片 → 有人问是否自己直播 → 主角顺势开小直播间。

第一次自己的直播仍以打天梯、聊天、偶尔解释为主，不直接变成Dota讲师。

### 20：理解型公众认知升级——C → B → D

1. 先把大家熟悉的现象讲出更深的条件和因果；
2. 再基于公开信息提前判断比赛下一步；
3. 更晚才进入冷门英雄、非主流位置、出装、选人禁用和职业创新。

目标是形成：

> **看得深 → 判断得早 → 真能把研究做成比赛答案。**

## 三、开篇首批执行原则：21—26

### 21：TI10后的系统触发

采用B的结构，但具体场景不锁死：

> **先让主角完整承受TI10第五局和Ame再次倒在决赛舞台上的结果；主角自身先产生“如果是我呢 / 我也想站上去”的欲望；系统随后出现。**

系统回应人物选择，不制造人物动机。

### 22—23：利用传统系统文预期做反向处理

主角是2021年的现代年轻人，不需要长篇震惊“什么是系统”。

他会天然预期：系统可能给属性、答案、奖励、未来信息。

但第一次TI10历史模拟与赛后复盘快速告诉他：

- 系统非常强；
- 但不替他思考；
- 不给“正确答案”；
- 不允许用通宵/梦中训练绕过正常恢复。

主角当晚只做有限粗复盘后睡觉，第二天再继续。

### 24：第一周的问题域

可以从中路、神符、辅助移动和兵线进入，但必须往深处挖。

当前最有价值的母题之一：

> **辅助“没露头”不是最关键的信息，真正重要的是他有没有条件离开原来的线。**

并进一步升级成：

> **主角不是要一个人看完整张地图，而是要知道下一次决策缺哪条信息，以及是否值得提前向队友问一句。**

边路实时血蓝、技能交换、拉野/封野、核心是否能单独站线等不能默认由二号位自己掌握；很多信息必须来自队友交流。

另一条可迁移母题：

> **线权的价值不是“把兵推过去”，而是购买一段不用回来处理兵线的行动窗口。**

### 25：表现成长——综合呈现

排名/分数可以涨得很快，但正文不靠连续报数字升级。

优先通过：

- 更高质量的对局名单；
- 反复出现的职业/主播ID；
- 同一批高手开始记住主角ID；
- 对局里的影响力和稳定性；

来让读者感知环境升级。

具体分数与排名待下一批结合2021中国天梯生态核验。

### 26：Zhou第一次明确记住主角——D的压缩写法

不连续展开多盘天梯。

正式写时只写一盘代表性对局，在选人阶段用类似：

> “又是这个中单，最近老排到他。”

一句话交代此前已经反复相遇。

这一盘用主角的信息需求、简短沟通、地图行动和实际收益证明实力，不靠“一盘连续单杀震惊职业圈”。

工作稿：`06_story/early-zhou-recognition-scene.md`。

## 四、比赛创新与Meta科研：已确认创作规则

详见 `06_story/match-innovation-rules.md`。

### 版本门

所有创新先确定：

> 日期 → 当期版本 → 英雄状态 → 装备状态 → 地图规则 → 是否进入队长模式。

不得把未来加强、重做、命石、先天技能、新地图机制等倒灌到旧版本。

### 英雄强度门

优先研究三类素材：

1. **高分天梯强、职业采用少**：重点研究采用障碍；
2. **冷门但功能独特**：通过阵容和选人禁用创造适用条件；
3. **原创位置/出装/资源模型**：必须解释对线、资源、时间点、团队职责、反制和失败条件。

不能为了爽点把当期明显弱的英雄强行写成无解答案。

### Meta领先与预反制

作者确认主角的科研优势可以非常强。

长期可形成：

> **发现Meta → 把Meta职业化 → 预演别人怎样复制/针对 → 提前准备反Meta → 对手再反过来研究主角。**

主角不仅更快理解“什么强”，还会更早研究：

> **这个强势答案会怎样死亡。**

可准备：

- 同体系第二英雄；
- 同英雄不同位置；
- 对手抢走后反过来克制；
- 故意展示第一版诱导禁用，再切第二套；
- 针对对手常见复制方式预先改变资源/时间点；
- 体系失效后仍能转回正常阵容的退路。

这不是预知未来。对手可以不按预测复制、找到第三种答案、用绝活绕过理论，甚至反利用主角的预判。

因此后期允许出现：

> **Meta → 反Meta → 反反Meta。**

## 五、直播与技术内容的长期边界

直播是中等权重长期副线，不是主职业。

主角可以通过直播：

- 公开验证假设；
- 解释版本/英雄；
- 做赛后复盘；
- 接受观众反例；
- 形成切片与社区扩散；
- 让公开知识被其他高分玩家/职业队吸收并反过来对付自己。

但直播首先仍是“一个人在打游戏”。

技术表达默认采用：

> **一句白话观察 → 一个具体动作 → 比赛结果验证 → 必要时补一层原因。**

避免连续理论课。

当前第一场“理解型出圈”场景只是工作稿，不锁正文。经作者反馈后，已从“放六分钟神符换边线资源”升级成：

> **主动放符 → 预判拿符中单最自然的兑现方向 → 提前处理自身中线并和边路确认拖延条件 → 后手传送形成反打 → 人头/塔权等明显胜势。**

厉害感来自主角提前看见连续两三步，而不是把普通资源交换解释得很高级。

工作稿：`06_story/first-stream-understanding-breakout-scene.md`。

## 六、正文技术场景审查规则

详见 `06_story/early-arc-risk-guardrails.md`。

长期重点防止：

- 技战术写成论文；
- 主角所有判断都被作者保证正确；
- 直播沦为作者借角色讲课；
- 信息来源不合理；
- 二号位被写成默认唯一指挥；
- 所有能力同时无成本补齐。

但不再把“变强太快”本身视为错误。

核心原则：

> **可以快，只要读者看得懂为什么快；真正不能省掉的是对手、版本和队伍对这种强度产生的反应。**

## 七、中文Dota叙事规范：已确认

详见 `00_meta/dota-cn-language-style.md`。

正文游戏内容优先使用对应版本的简体中文官方/社区通用表达：

- 黑皇杖，不写BKB作为默认正文词；
- 肉山，不写Roshan作为默认正文词；
- 传送/传送卷轴，不写TP作为默认正文词；
- 天梯，不以Rank作为默认正文词；
- 选人禁用，不以BP作为默认正文词；
- 位置摇摆、地图控制等优先中文自然表达。

英文主要保留在外国解说/采访原话、选手ID、战队名和研究检索层。
