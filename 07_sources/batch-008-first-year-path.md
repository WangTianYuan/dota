# 本批证据结论

高置信现实骨架：

> Aries Tour2 6-1升S
> → Tour3 4-3
> → TI11预选现实先2:0 VG、再0:2 RNG、后1:2 iG出局
> → 中国第2/3可进LCQ
> → LCQ只有2个TI名额。

小说当前推荐分叉：

> 保留胜VG与负RNG
> → 翻转iG 1:2为2:1
> → 再胜VG
> → 负XG
> → 中国第3
> → LCQ出线
> → TI11。

该分叉仍是故事方案，尚未由作者锁定。
