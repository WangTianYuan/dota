# 2022 Aster.Aries → TI11 资格路径研究

ID: tournament-research:2022-aries-ti11-path
更新：2026-09-12
状态：现实基线已建立；小说资格路径待作者选择。

## 1. 现实基线

### Tour 2：中国区A级 / Division II

- 时间：2022-03-14 ～ 2022-04-26。
- Aster.Aries现实战绩：**6-1，第二名，升入Tour 3 S级/Division I**。
- 唯一系列赛失利：2022-03-18，0:2负Dandelion Esport Club（DEC）。
- 现实3月18日Aries中单仍为White丶Album；Xwy随后在3月21日对ShenZhen的系列赛中代表Aries出场。
- 现实资料还显示这一阶段Aries存在较特殊的替补/中单使用情况，Perfect World曾就超过常规替补场次的争议给出“存在减轻情形，Valve知情”的解释。该信息目前来自二级转述，未找到公开原始公告正文，因此只作为“现实确有阵容不稳定”的支持，不把具体内部原因写死。

### Tour 3：中国区S级 / Division I

- Aster.Aries现实战绩：**4-3，第5名（含加赛排序）**。
- 现实首轮即在2022-06-07 0:2负Team Aster主队。
- **2022-06-24 PSG.LGD 2:0 Aster.Aries**，是小说中主角第一次正式职业赛对阵Ame的天然历史锚点。
- 这支Aries已经证明能在S级赢下多支队伍，因此小说不需要把一支纯弱旅从零抬成争冠队。

### TI11中国区预选

现实Aries路径：

1. 2022-09-08：Aries 2:0 Vici Gaming；
2. 2022-09-10：RNG 2:0 Aries；
3. 2022-09-11：iG 2:1 Aries；
4. 最终5–6名，未获得TI或LCQ资格。

现实最终结果：

- RNG：第1，直接进入TI11；
- Xtreme Gaming：第2，进入LCQ；
- Vici Gaming：第3，进入LCQ；
- iG：第4；
- Aries：第5–6。

### TI11 Last Chance Qualifier

- 时间：2022-10-08 ～ 2022-10-12；新加坡线下。
- 12支队伍：每个赛区地区预选第2、第3。
- 小组赛：两组各6队，单循环BO2；前4进入胜者组，其余进败者组。
- 淘汰赛：双败BO3。
- 最终只有两队晋级TI11；现实为Team Secret与Team Liquid。
- 中国现实参赛队为XG与VG。

## 2. 三种小说资格路径

### 方案A：Aries中国区预选夺冠，直接TI

需要至少明显改写：
- 与RNG的0:2；
- 后续胜者组/总决赛；
- 同时重写RNG/XG的资格结构。

优点：
- 节奏最快；
- 主角首年直接成为中国区最受关注新人。

代价：
- 对现实强弱改写最大；
- 省掉LCQ这个很好的第一次国际强度考试；
- 更容易让第一年成长过快，提前接近“带队扫平中国区”的感觉。

**当前不推荐。**

### 方案B：Aries中国区第3 → LCQ → 出线TI

这是当前最推荐路径。

可以在尽量保留现实的前提下这样变化：

1. **Aries 2:0 VG** —— 保留现实结果；
2. **RNG 2:0 Aries** —— 保留现实结果，让主角知道中国最强队仍有明显差距；
3. **Aries 2:1 iG** —— 只把现实1:2的小比分翻转；
4. **Aries再次击败VG** —— 现实两队第一次交手已经是Aries 2:0，因此并非凭空制造克制；
5. **Aries负于XG** —— 最终中国区第3，XG仍第2，RNG仍第1；
6. Aries与XG进入LCQ，VG被挤出。

这条路线只对预选赛做有限改写，却带来完整的国际考试：Secret、Liquid、T1、Virtus.pro、Na`Vi、nouns等不同赛区风格均在现实LCQ参赛池中。

LCQ具体分组和对手不应直接照搬现实VG的位置，因为Aries进入后抽签/赛程可能产生蝴蝶效应；只保留赛事格式和参赛池硬事实。

优点：
- 现实改写最小且非常容易解释为“主角让两场关键BO3发生变化”；
- 保留RNG/XG当时的中国顶级地位；
- 第一次出国/线下国际赛自然成为主角职业生涯的新层级考试；
- 即使最终进TI，也已经付出地区预选+LCQ两层成本，不显得系统直接送资格。

代价：
- 为进入TI，LCQ必须再击败多支世界级/准世界级队伍，主角和Aries需要在9月到10月之间完成一次明显升级；
- VG会失去现实LCQ资格，这是明确的蝴蝶效应，需要在世界线日志记录。

**当前推荐。**

### 方案C：中国区仍5–6，首年不进TI

优点：
- 最大程度保留真实赛果；
- 可把TI11作为主角第一次以职业选手视角旁观的失败目标。

代价：
- 与已确定的“第一年快速进入世界舞台”节奏冲突；
- 2022整年高潮不足；
- 后续主角在Aster主队得到重用的说服力仍可成立，但小说第一卷/第一阶段缺少最大赛事兑现。

**作为现实主义兜底保留，但不推荐。**

## 3. 当前推荐：方案B，且优先中国区第3

为什么不是第2：

- 第3只需要Aries在败者组把现实接近的iG系列翻过来，并再次击败已经真实2:0赢过的VG；
- 仍可让XG在败者组决赛击败Aries，保留XG现实更强的整体位置；
- RNG仍直接进TI，XG仍进LCQ，两支现实中国强队的主干轨迹变化较少；
- 主角不是“一来就成为中国区冠军中单”，但已经把一支现实5–6名队伍推进到国际门口。

推荐的小说资格链：

> Tour2 A级6-1升S
> → Tour3 S级4-3上下（不必强改成冠军）
> → TI11中国预选第3
> → LCQ出线
> → TI11。

这里仍未锁：
- Tour3是否保留4-3原战绩；
- 预选与iG、VG具体比分之外的比赛内容；
- LCQ到底走胜者组还是败者组；
- LCQ淘汰哪些真实队伍；
- TI11最终名次。
